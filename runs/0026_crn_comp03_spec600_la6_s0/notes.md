FIRST NATIVE RUN ON THE 90/10 SNR DISTRIBUTION. Same configuration as run 0025 (9.3M parameters, LSTM 512, encoder widths x1.5, compressed-magnitude loss at weight 600, compression 0.3, lookahead 6, 176.6 ms total latency), but trained on the new distribution rather than the old flat U(-5,+15). Every run up to 0025 studied for the old exam: they were trained on mixtures where a quarter sat below 0 dB, and are only being scored on the new set through rescore_runs.py. This is the first model whose training and evaluation distributions agree, so it becomes the baseline everything after it is measured against. Reference point: run 0025, trained on the old distribution, scores PESQ 2.098 and STOI 0.8824 on the new validation set. Anything less than that would mean training on the easier distribution actively hurts, which would be worth knowing.
