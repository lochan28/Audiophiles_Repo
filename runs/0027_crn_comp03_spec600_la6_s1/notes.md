Seed 1 of a three-way replicate on the current 90/10 SNR distribution, RUN CLEAN FROM SCRATCH. An earlier attempt at this run was interrupted at epoch 92 and resumed; it was discarded rather than used, because resuming restarts the ReduceLROnPlateau patience counter and the scheduler had already fired fourteen times, taking the learning rate from 3e-4 down to 2.9e-7. The effect was almost certainly negligible at that learning rate, but this experiment exists to measure how much two IDENTICAL runs differ, and a resumed run is a different treatment. Contaminating the very measurement meant to detect small differences was not worth the forty minutes saved.
